#
# RULE: if a test imports a module, that module MUST be listed here.
#
# Installing something by hand into the venv without recording it here produces
# green on your machine and red on the next one. The legacy repo lost several
# waves to exactly this: 18 tests were red purely because python-docx was
# installed locally but never declared.
#
# RULE: pins are resolved as a SET, in one `pip install`, never package by
# package. Pinning independently produced an unsatisfiable requirements file
# here -- a hand-chosen botocore conflicted with what dlt's s3fs needed, and the
# break only surfaced on a clean venv rebuild. Change one pin, re-resolve all of
# them.
