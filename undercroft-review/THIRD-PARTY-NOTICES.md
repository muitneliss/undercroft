# Third-party materials

- Undercroft design vocabulary and source reference: [muitneliss/undercroft](https://github.com/muitneliss/undercroft), checked at `116a41e` (release 1.53.0). The upstream MIT license is copied without alteration as `UPSTREAM-LICENSE.txt`.
- Self-hosted WOFF2 files and font declarations were copied from that snapshot, without changing font binaries. Attribution and the upstream license file remain alongside them in `assets/fonts/`.
- Archivo: Omnibus-Type. EB Garamond: Georg Duffner / Octavio Pardo. Spline Sans Mono: Eben Sorkin / Mirko Velimirović. The upstream font README identifies all three as SIL Open Font License 1.1.
- The copied `OFL.txt` contains generic placeholder copyright lines in the source repository. This package preserves it verbatim rather than inventing copyright dates or ownership statements. Confirm family-specific notices before independently redistributing modified font assets; application integration should simply reuse its existing fonts.

This is an unaffiliated design review, not an official release or an assertion of maintainer endorsement. No customer dataset, credential, production trace or live-site screenshot is included.
