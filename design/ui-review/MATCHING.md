# Matching the mockup to apps/ui

Baseline: release 1.57.0 (`ad98ec9`; `apps/ui` is the same as at `0a0aade`, after #352, #353, #355, #356, #364, #366, #367). The
mockup in this folder (`index.html`, `assets/app.js`, `assets/workspace.js`) was drawn against
`116a41e`; several of its behaviours have since shipped, sometimes with a different layout,
wording or placement. This file says, screen by screen, where each mockup screen lives in
`apps/ui/src` today and what must change for `apps/ui` to look and behave like it.

How to read it: open the mockup (`node preview.cjs`, then `http://127.0.0.1:8772/#<route>`,
switch to EN in the header) beside the file named in the second column. Each row is one screen,
panel or control group. Paths are relative to `apps/ui/src/`. Dictionary keys are
`i18n/en.ts` and `i18n/vi.ts`; every new word is a key in both, Vietnamese first
(`.claude/rules/i18n.md`). New URL state goes in the address, new drafts in `store.ts`, never
`useState` (`.claude/rules/state.md`).

Verdicts:

- **Match**: already the same in behaviour and near enough in look. Nothing to do.
- **Change**: `apps/ui` must change. The last column says exactly what.
- **Keep code (reason)**: the mockup differs, and a merged ADR, `CLAUDE.md`, a
  `.claude/rules/*.md` file, `apps/ui/DESIGN.md`, the design contract
  (`docs/design/operator-and-reader-paths.md`) or a missing server field says the code is
  right. Do not change it to match.
- **Not a target**: a prototype convenience (the test-controls panel, the review banner, the
  hash router, in-memory fixtures). Do not build it.

Standing rules that decide many rows below: no modal (confirmations are a `<details>` fold
holding a `.hinge`); every transition `steps(n, end)` (ADR 0014); times in Asia/Singapore
(`lib/when.ts`), never the mockup's UTC+7; role values stay `viewer`, `member`, `admin` in both
languages; lineage draws declared relations only (ADR 0092, 0097); Reports computes no figure it
cannot stand behind (ADR 0090). Bands the mockup does not draw (Ingest keys, Display name,
Document kinds, Reference, Tests) stay where they are.
